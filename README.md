# optiscaler-deps

Binários de terceiros **compilados a partir do código-fonte oficial**, por GitHub Actions, para o
OptiScaler Client Next baixar com versão e SHA-256 fixados. Nada aqui é modificado: cada release
aponta a tag e o commit do fonte usado, e o log completo do build fica no Actions.

| Componente | Fonte oficial | Licença | Workflow |
|---|---|---|---|
| dlssg-to-fsr3 (Nukem9) | https://github.com/Nukem9/dlssg-to-fsr3 | GPL-3.0 | `build-dlssg-to-fsr3.yml` |

## Código-fonte (GPL-3.0)

Os binários de `dlssg-to-fsr3` são distribuídos sob a GPL-3.0. O código-fonte correspondente é a tag
indicada em cada release em https://github.com/Nukem9/dlssg-to-fsr3 (o commit exato também está nas
notas da release). Os créditos e direitos são dos autores originais.
